Vice Coast — Cover Studio: an offline, no-library cover maker that turns any photo and caption into GTA 6-style multi-panel cover art. Six layouts, five colour grades (Vice Sunset, Neon Nights, Golden Hour, Palm Noir, Pastel Palm), and PNG export at 1080×1080, 1080×1350 and 1920×1080. No network requests, no Rockstar assets — all original.

## Run it

```sh
node serve.ts
```
